# AI Resume Analyzer

An AI-based web application that analyzes resumes and compares them with job
descriptions using NLP techniques.

## Overview
This project extracts text from resume PDFs and evaluates how well a resume
matches a given job description by identifying common skills and keywords.

## Features
- Resume PDF upload
- Job description analysis
- Skill matching using NLP
- Match percentage score

## Tech Stack
- Python
- Flask
- spaCy
- HTML/CSS

## How It Works
1. Resume text is extracted from PDF
2. Job description is processed
3. Common skills are identified
4. Match score is calculated
